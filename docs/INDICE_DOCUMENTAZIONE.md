## 🎯 GUIDA RAPIDA: QUALE DOCUMENTO LEGGERE?

### Per Ruolo:

#### 👨‍💼 **CEO / Management**
1. Leggi: `EXECUTIVE_SUMMARY_TELEMEDCARE_INVITALIA.md`
2. Poi: `RIEPILOGO_COMPLETO` (sezione Executive Summary + Roadmap)

#### 👨‍💻 **Developer (Nuovo)**
1. **INIZIA DA:** `README.md` (setup base)
2. Poi: `RIEPILOGO_COMPLETO` (architettura)
3. Poi: Esplora codebase con reference a documentazione

#### 👨‍💻 **Developer (Esperto)**
1. Usa: `RIEPILOGO_COMPLETO` come reference continuo
2. Consulta: File `ANALISI_*` per troubleshooting
3. Contribuisci: Aggiorna docs a ogni cambio significativo

#### 🧑‍💼 **Operatore Dashboard**
1. Leggi: `DOCUMENTAZIONE_FUNZIONALE` (sezione Dashboard + Guide Operative)
2. Usa: `RIEPILOGO_COMPLETO` (sezione Guide Operative + Troubleshooting)
3. Pratica: Dashboard `/dashboard` con training sandbox

#### 🧪 **QA / Tester**
1. Leggi: `DOCUMENTAZIONE_FUNZIONALE` (workflow completi)
2. Usa: `RIEPILOGO_COMPLETO` (sezione Testing End-to-End)
3. Crea: Test case based su stati workflow documentati

#### 🔐 **Security / Compliance**
1. Leggi: `DOCUMENTAZIONE_FUNZIONALE` (sezione Sicurezza e Privacy)
2. Leggi: `RIEPILOGO_COMPLETO` (sezione Sicurezza e GDPR)
3. Verifica: Implementazione privacy by design

#### 💼 **Business Analyst**
1. Leggi: `DOCUMENTAZIONE_FUNZIONALE` (tutte le sezioni)
2. Leggi: `EXECUTIVE_SUMMARY` (metriche business)
3. Analizza: Dashboard Analytics per KPI reali
